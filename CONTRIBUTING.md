# Contributing

BeatScript is open source: the code is MIT (`LICENSE`), and BeatScript programs and all content are CC0-1.0
(`REUSE.toml` says which is which, path by path). It is built by one person, so contributions work like this:

- **Feature requests and bug reports are welcome.** Open an issue at
  https://github.com/stackdump/beatscript/issues and say what you wanted to do and what happened.
- **Outside code and pull requests are not accepted.** A pull request will be closed unread. This keeps the
  licence and the authorship of the code simple; it is not a judgement of the work.
- **Programs are yours to share.** Programs stored on beatscript.app are CC0 by default: fork, remix and publish
  them anywhere. See https://beatscript.app/authorship.
